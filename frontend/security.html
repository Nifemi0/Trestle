SECURITY MODEL

Honest testnet boundary.

Trestle is not mainnet certified yet. This page states what is protected now and what must change before real funds.

CURRENT

Testnet trust model

TrustedRelayerIsm accepts messages processed by the configured relayer/deployer key. Synthetic remote assets are botUSDT testnet representations.

PROTECTED

Router-scoped relay

The relayer only processes messages whose origin, destination, sender and recipient match a Trestle route.

KNOWN LIMIT

Single trusted key

The deployer/relayer key remains privileged in this prototype. Mainnet requires separated keys and validator/multisig ISM.

NEXT

Mainnet path

Validator/multisig ISM, isolated relayer key, rate caps, RPC redundancy, alerting and external audit.
